      正規表現サンプル
      
      
      
        パス・クライアント IP・全文検索・ソースファイルの各フィールドは正規表現に対応しています。
        マッチは大文字小文字を区別しません。ステータス（例: 500 / 4xx）と
        メソッド（例: GET）は完全一致であり、正規表現ではありません。
      
      
      
      
        
          
      
            パターン
            対象
            説明
            マッチ例
          
      
              
        
          
      
            /api/
            パス
            パスの部分一致
            /api/users
          
      
          
      
            /api/users/\d+
            パス
            数値 ID を含む API パス
            /api/users/12345
          
      
          
      
            192\.168
            クライアント IP
            プライベート IP の prefix（XFF 含む）
            192.168.1.10
          
      
          
      
            203\.0\.113\.\d+
            クライアント IP
            特定レンジの IP
            203.0.113.50
          
      
          
      
            access_log
            ソースファイル
            ファイル名の部分一致
            C:\logs\apache\access_log
          
      
          
      
            error\.log
            ソースファイル
            ドットをリテラルに
            error.log.2025-06-20
          
      
          
      
            error|500
            全文検索
            いずれかに一致（OR）
            Internal Server Error, HTTP 500
          
      
          
      
            "GET /api/
            全文検索
            リクエスト行の部分一致
            "GET /api/users HTTP/1.1"
          
      
          
      
            HTTP/1\.1" 5\d\d
            全文検索
            5xx ステータスを含む行
            HTTP/1.1" 502
          
      
          
      
            curl/
            全文検索
            User-Agent に curl を含む
            curl/8.0
          
      
          
      
            ^203\.0\.113
            全文検索
            行頭が特定 IP（XFF 先頭）
            203.0.113.50 10.0.0.5 - - [...]
          
      
          
      
            ^(?!.*\/health)
            全文検索 / パス
            指定文字列を含まない（否定先読み (?!…)）。/health を除く行・パス
            /api/users（/health は除外）
